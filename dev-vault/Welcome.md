# Organized beta development vault

This folder is an isolated test vault. Open **this folder**, never a primary vault, when exercising unreleased plugin builds.

Install the beta's three assets in `.obsidian/plugins/organized/`, enable the plugin, and restart Obsidian. Match custom daily notes to `Daily/YYYY-MM-DD.md`. Task records default to `Tasks/`.

Auto-forward is enabled by default; turn it off before opening today's daily note if you want manual scheduling only.

Try creating an ordinary task by typing `- [ ] ` on a new line. The native picker owns the draft; cancellation creates no task record. Existing and pasted checkboxes remain untouched until explicitly attached.

Use the README marker table and `docs/testing.md` checklist. Do not place personal data here or commit generated task records.
